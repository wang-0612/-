# Web 渗透测试概览

> [!warning] 合规声明
> 本分区内容仅用于**授权环境下的安全测试、CTF 竞赛、靶场练习与防御学习**。未经授权对他人系统进行扫描、爆破、注入或上传属于违法行为。请只在自有环境或取得书面授权的目标上实践。

Web 渗透测试的本质是**模拟攻击者的思路，在授权范围内发现并验证安全风险**。课件围绕「信息收集 → 暴力破解 → XSS → 文件上传」四条主线展开，Burp Suite 是贯穿始终的核心工具。

    D --> E[整理证据与报告]
