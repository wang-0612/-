# 端口扫描

> [!warning] 合规声明
> 端口扫描会与目标主机直接交互，仅可在**获得授权**的资产上进行。

## 端口基础

计算机"端口"是英文 **port** 的意译，可以理解为计算机与外界通讯交流的出口。端口范围为 `0~65535`，共 65536 个。

端口是服务器与客户端交互的接口。常见端口能直接暴露服务类型，例如 **3389 端口开放**通常意味着目标为 Windows 且开启了远程桌面服务。因此端口扫描是渗透测试中非常重要的一步。

### 常见端口

| 端口 | 服务 | 端口 | 服务 |
|------|------|------|------|
| 21 | FTP | 3306 | MySQL |
| 22 | SSH | 3389 | RDP 远程桌面 |
| 23 | Telnet | 5432 | PostgreSQL |
| 53 | DNS | 6379 | Redis |
| 80 | HTTP | 7001 | WebLogic |
| 135 | RPC | 8000 / 8080 | 常见 Web 服务 |
| 443 | HTTPS | 9200 | Elasticsearch |
| 445 | SMB | 11211 | Memcached |
| 1433 | SQL Server | 27017 | MongoDB |
| 1521 | Oracle | 50070 | Hadoop HDFS |

## nmap

nmap 是一款开源免费的针对大型网络的端口扫描工具，可以检测：

- 目标主机是否在线
- 主机端口开放情况
- 主机运行的服务类型及版本
- 操作系统与设备类型

### 常用参数

| 参数                | 解释                                    |
| ----------------- | ------------------------------------- |
| `-sP`             | Ping 扫描                               |
| `-sS`             | 快速扫描，SYN 半开放扫描                        |
| `-sT`             | TCP 全连接扫描（默认）                         |
| `-sU`             | UDP 端口扫描，不准确                          |
| `-sA`             | 穿过防火墙的规则集，速度慢                         |
| `-P0`             | 空闲扫描，无 Ping 扫描                        |
| `-PN`             | 防火墙禁 Ping，不使用 Ping 扫描                 |
| `-PR`             | ARP Ping 扫描，速度很快                      |
| `-PS`             | TCP SYN Ping 扫描                       |
| `-PA`             | TCP ACK Ping 扫描                       |
| `-sV`             | 探测端口服务及版本                             |
| `-sC`             | 默认脚本扫描，主要搜集应用服务信息（`--script=default`） |
| `-O`              | 探测目标系统版本                              |
| `-A`              | 包含 `-sV`、`-O`，全面系统检测、脚本检测、漏洞扫描（有误报）   |
| `-p`              | 指定端口号，如 `80,81,8000-9000`             |
| `-T`              | 扫描速度 T0~T5，默认 T3，越快精度越低               |
| `--open`          | 只显示开放的端口                              |
| `-v / -vv`        | 显示详细信息，`-vv` 更详细                      |
| `-iL`             | 从文件导入要扫描的 IP 列表                       |
| `-oN / -oX / -oG` | 报告写入文件：正常文本 / XML / grepable          |
| `--exclude`       | 排除不需要扫描的 IP                           |

### 基本使用

```bash
nmap 192.168.23.1/24
# 默认发送 ARP ping 数据包，探测 1-10000 范围内开放的端口
```

### 主机发现与系统识别

```bash
nmap -sP 192.168.1.0/24                  # Ping 扫描，列出响应主机，不扫端口
nmap -O 192.168.23.1                     # 操作系统版本探测
nmap -O --osscan-limit 192.168.23.1      # 探测操作系统版本详细信息
nmap -O --osscan-guess 192.168.23.1      # 猜测操作系统版本
nmap -A 192.168.23.1                     # 操作系统 + 服务版本等全面探测
```

### 端口扫描

```bash
# 默认 TCP 全连接扫描常见端口
nmap -sT 192.168.23.1 -p 21,22,23,53,80,135,443,445

# 常用：快速扫描 1-3000，只显示开放端口
nmap -sS 192.168.23.1 -p 1-3000 --open -vv

# 不适用 Ping 扫描（防火墙禁 Ping）
nmap -PN 192.168.23.1 -p 1-3000

# ARP 扫描，局域网防火墙不拦截，速度快
nmap -PR 192.168.23.1 -p 1-3000

# 空闲扫描，不留下记录
nmap -P0 192.168.23.1 -p 1-3000

# 服务版本 + 全面探测
nmap -sV 192.168.81.148 -p 3389,5985,6588,999,21,80 -A
```

### 格式化输出

```bash
# 端口信息 + 系统探测 + 基础扫描，导出 XML
nmap -sV -A 192.168.23.1 -p 80,88,135,139,443,445,903,1080,1688,3306,5357 -oX mysite.xml

# 用 XSL 模板把 XML 渲染成 HTML
xsltproc -o mysite.html mode.xsl mysite.xml

# 浏览器打开
firefox mysite.html
```

## masscan

masscan 是 Kali 下集成的高效扫描器，速度非常快。

### 常用参数

| 参数 | 解释 |
|------|------|
| `--ping` | 发送 ICMP 数据包，进行主机存活探测 |
| `--adapter-ip` | 指定发包的 IP 地址（伪造 IP） |
| `--adapter-port` | 指定发包源端口 |
| `--adapter-mac` | 指定发包的源 MAC 地址 |
| `--router-mac` | 指定网关 MAC 地址 |
| `--exclude` | IP 地址范围黑名单 |
| `--excludefile` | 指定 IP 黑名单文件 |
| `--includefile / -iL` | 读取范围列表进行扫描 |
| `--wait` | 退出前等待接收数据包的时间，默认 10 秒 |
| `-p` | 指定端口类型及范围，如 `-p U:1024-1100` |
| `--rate` | 指定线程数，推荐 1000~3000 |
| `--banners` | 抓取端口服务信息，仅支持部分协议 |
| `--open-only` | 只显示开放端口 |
| `--http-user-agent` | 使用指定 User-Agent 发送 HTTP 请求 |
| `-sL` | 不执行扫描，创建随机地址列表 |
| `--output-format` | 输出格式：xml / binary / grepable / list / JSON |
| `--output-filename` | 输出文件名 |
| `-oX / -oB / -oG / -oL / -oJ` | 按格式输出文件 |

### 基本用法

```bash
masscan 192.168.23.1 -p 1-3000
```

### 枚举网段

```bash
masscan -sL 10.0.0.0/24 > c段.txt
masscan -sL 10.0.0.0/16 > b段.txt
masscan -sL 10.0.0.0/8  > a段.txt
```
