# 目录信息收集

> [!warning] 合规声明
> 目录扫描会产生大量请求，仅可在**获得授权**的目标上进行，避免影响业务可用性。

目录扫描的目标是发现网站上未公开的路径与文件：

- 寻找网站后台管理入口
- 寻找未授权访问的界面
- 寻找网站更多隐藏信息
- 摸清网站有多少目录、多少页面，还原整体结构
- 发现敏感文件、后台文件、数据库文件和信息泄露文件

## robots.txt

**Robots 协议**（Robots Exclusion Protocol，"网络爬虫排除标准"）用于告诉搜索引擎哪些页面可以抓取、哪些不能抓取，同时也可能**记录网站的基本目录**。

```text
https://example.com/robots.txt
```

> [!tip] 为什么先看 robots.txt
> 管理员常把后台、管理目录写进 `Disallow`。这些路径本意是"别让爬虫抓"，但等于直接告诉攻击者哪里有敏感目录。

## dirsearch

dirsearch 是一个基于 Python 3 的命令行工具，用于暴力扫描页面结构，包括网页中的目录和文件。

```bash
pip install -r requirements.txt
python dirsearch.py -u 目标地址
```

### 常用参数

| 参数 | 作用 |
|------|------|
| `-h` | 查看帮助 |
| `-u` | 指定目标 URL，最好带上协议（http / https） |
| `-L` | 指定 URL 列表文件 |
| `-e` | 指定网站类型 / 扩展名，如 `php,jsp,asp,aspx,do,action,cgi,pl,html,htm,js,json,tar.gz,bak`；`-e *` 代表所有 |
| `-w` | 指定字典 |
| `-t` | 指定线程数（默认 25） |
| `-r` | 递归扫描，扫到目录后继续向下挖掘 |
| `--random-agents` | 使用随机 User-Agent |
| `-H` | 使用指定 Header，如 `--header "Referer: example.com"` |
| `-m` | 指定 HTTP 请求方式，默认 GET |
| `-d` | 发送的 data 数据 |
| `--cookie` | 添加 Cookie |
| `--proxy` | 添加代理，如 `--proxy 127.0.0.1:1080` |
| `-i` | HTTP 状态码白名单，如 `200,300-399` |
| `-x / --exclude-status` | 排除指定状态码，如 `301,403,500-599` |
| `--exclude-texts` | 按文本排除响应，如 `"Not found","Error"` |
| `--exclude-regexps` | 按正则排除响应 |
| `-o` | 指定报告输出地址 |
| `--format` | 报告格式：simple / plain / json / xml / md / csv / html / sqlite |
| `--log` | 输出扫描日志文件（一般不常用） |

### 使用示例

```bash
# 基础扫描
python dirsearch.py -u http://target.com

# 指定扩展名与线程
python dirsearch.py -u http://target.com -e php,asp,aspx,jsp,bak -t 30

# 递归扫描 + 排除 404/403
python dirsearch.py -u http://target.com -r -x 404,403

# 使用代理与随机 UA
python dirsearch.py -u http://target.com --proxy 127.0.0.1:8080 --random-agents

# 输出 HTML 报告
python dirsearch.py -u http://target.com --format html -o report.html
```

## 常见敏感路径类型

| 类型 | 示例 / 说明 |
|------|------------|
| 后台管理 | `/admin`、`/login`、`/manage`、`/system` |
| 配置文件 | `.env`、`config.php`、`web.config`、`.git/config` |
| 备份文件 | `www.zip`、`backup.sql`、`index.php.bak` |
| 数据库文件 | `.mdb`、`.sql`、`.sqlite` |
| 信息泄露 | `phpinfo.php`、`readme.txt`、`robots.txt` |
| 编辑器 | `ewebeditor`、`kindeditor`、`ueditor` |
| 上传目录 | `/upload`、`/uploads`、`/files` |

> [!note] 状态码的意义
> - `200`：存在且可直接访问
> - `301 / 302`：存在，发生跳转（可能跳登录页）
> - `403`：存在但禁止访问（值得继续尝试绕过）
> - `404`：通常不存在
> - `500`：服务端报错，可能存在参数问题
