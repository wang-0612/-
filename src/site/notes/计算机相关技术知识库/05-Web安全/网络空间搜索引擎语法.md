# 网络空间搜索引擎语法

> [!warning] 合规声明
> 搜索引擎语法只用于发现公开信息。请勿利用其定位并攻击未授权资产。

## Google 基本语法

Google 默认使用 **AND** 逻辑：输入多个关键词时，会返回同时包含这些关键词的页面。

| 语法 | 含义 | 示例 |
|------|------|------|
| `AND` | 缺一不可（默认逻辑） | `program google` → 同时包含两个词 |
| `OR` 或 `|` | 两者皆可，必须大写，前后有空格 | `program OR google` |
| `""` | 精确匹配词组，不拆分 | `"programgoogle"` |
| `-` | 排除关键词，减号前有空格、后紧贴关键词 | `program -google` |
| `+` | 强制包含通常被忽略的词 | `+www` |
| `*` 或 `?` | 占位通配符（stemming 填充） | `"l*Messi"` |

> [!tip] 使用细节
> `OR` 必须大写，小写无效；`-` 前必须有空格，后面紧贴要排除的词；通配符查询整体要用英文半角双引号括住。

## Google 高级语法

| 语法 | 作用 |
|------|------|
| `site:` | 限制搜索范围为指定域名 |
| `inurl:` | 搜索 URL 中包含指定字符串的页面 |
| `intext:` | 只搜索 `<body>` 部分包含的文字（忽略标题、URL） |
| `intitle:` | 搜索标题中包含关键词的页面 |
| `filetype:` | 搜索指定后缀 / 扩展名的文件 |
| `inanchor:` | 搜索锚节点内容 |
| `cache:` | 查看搜索引擎缓存，如 `cache:secquan.org` |

### 常见组合

```text
# 查找后台地址
site:域名 inurl:login|admin|manage|member|admin_login|login_admin|system|user|main|cms

# 查找文本内容
site:域名 intext:管理|后台|登陆|用户名|密码|验证码|系统|admin|login|sys|password|username

# 查找可注入点
site:域名 inurl:aspx|jsp|php|asp

# 查找上传漏洞
site:域名 inurl:file|load|editor|Files

# 找 Web 编辑器
site:域名 inurl:ewebeditor|editor|uploadfile|eweb|edit

# 查找数据库文件
site:域名 filetype:mdb|asp|#

# 查看脚本类型
site:域名 filetype:asp|aspx|php|jsp

# 迂回策略入口
inurl:cms/data/templates/images/index/

# 其他字段
inbody:密码|登陆
intitle:后台管理
inanchor:登录
```

## Bing 语法

Bing 的语法与 Google 类似，常用的 `site:`、`inurl:`、`intitle:`、`filetype:`、`inbody:`、`ip:` 等均可使用：

| 语法 | 作用 |
|------|------|
| `site:` | 返回属于指定网站的网页；多个域可用 `OR` 分组 |
| `inurl:` | URL 中包含指定字符串 |
| `intitle:` | 标题中包含指定字符串 |
| `inbody:` | 正文内容包含指定字符串 |
| `inanchor:` | 锚节点包含指定字符串 |
| `filetype:` | 指定文件类型 |
| `ip:` | 查找指定 IP 的网站 |

## FOFA

官网：https://fofa.info/

FOFA 是网络空间测绘平台，可按组件、协议、端口、地区等维度检索资产。

### 逻辑运算符

- `&&` = AND（与）
- `||` = OR（或）
- `!=` = 非
- 支持使用括号组合条件

### 常用字段

| 语法 | 作用 |
|------|------|
| `domain="qq.com"` | 查询子域名 |
| `host=".gov.cn"` | 从 URL 中搜索 `.gov.cn` |
| `header="thinkphp"` | 从 HTTP 头中搜索 thinkphp |
| `port="6379"` | 查找开放 6379 端口的资产 |
| `ip="1.1.1.1"` | 搜索包含指定 IP 的网站 |
| `ip="220.181.111.1/24"` | 查询 C 网段资产 |
| `status_code="402"` | 查询服务器状态码为 402 的资产 |
| `app="通达OA网络智能办公系统"` | 搜索指定应用系统 |
| `country="CN"` | 搜索指定国家（编码） |
| `region="Henan"` | 搜索指定行政区 |
| `city="beijing"` | 搜索指定城市 |

### 组合示例

```text
title="powered by" && title!="discuz"

body="content=WordPress" || (header="X-Pingback" && header="/xmlrpc.php" && body="/wp-includes/") && host="gov.cn"
```
