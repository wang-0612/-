# 维护指南

> [!abstract] 本文用途
> 本知识库未来会持续**补充、修改、优化**。本页规定了目录职责、命名与标签约定、以及新增/修改内容的标准流程，让每次更新都有章可循。

## 目录结构与职责

```
计算机相关技术知识库/
├── 首页.md              ← 总入口：知识地图 + 分区导航（新增内容必须在此挂链）
├── 维护指南.md          ← 本页
├── 知识库全景.canvas     ← 画布版知识地图（分区文本框内挂链）
├── 知识库目录.base       ← 全部笔记的表格视图（Bases 自动生成，无需手改）
├── 01-Linux/            ← Linux 主题笔记
├── 02-Windows/          ← Windows 主题笔记
├── 03-数据库/           ← 数据库/SQL 主题笔记
├── 04-速查表/           ← 跨主题的一页速查
└── 99-参考资料/         ← 原始 PDF 与资料索引
    └── 资料原文/        ← PDF 原文（只增不改）
```

> [!important] 唯一原则
> 所有知识库内容都在本文件夹内；vault 根目录只保留 `.obsidian` 配置。这样无论 vault 放在哪里，整个文件夹就是完整的知识库。

## 新增一篇笔记的标准步骤

1. **建文件**：在对应分区目录新建 `主题关键词.md`（文件名即笔记名，也是 wikilink 目标）
2. **套模板**（frontmatter 必填）：

   ```yaml
   ---
   title: 笔记名
   created: 2026-10-13        # 实际创建日期
   tags:
     - 分区标签                # 如 Linux/命令、Windows/进程、数据库/MySQL
   aliases:
     - 备用名                  # 可选：别名，便于搜索和链接
   ---
   ```

3. **写正文**：沿用既有风格——表格整理参数、代码块放命令、`> [!tip]`/`> [!warning]` callout 放要点和坑
4. **挂链三处**（缺一不可）：
   - [[计算机相关技术知识库/首页\|首页]] 对应分区列表加一行 `- [[笔记名]]`
   - [[知识库全景\|知识库全景]] 双击对应分区的文本框，加一行 `- [[笔记名]]`
   - （可选）相关内容已链接：在新笔记与旧笔记中互加 wikilink
5. **验证**：打开 [[知识库目录\|知识库目录]]（自动生成，无需手改），确认新笔记出现在对应分组

## 修改与重命名

- **改内容**：直接编辑正文即可，Obsidian 实时保存
- **重命名笔记**：在 Obsidian 文件列表中**右键重命名**（不要在资源管理器里改）——wikilink 会自动更新，不会产生死链
- **移动笔记**：同样在 Obsidian 里拖动，链接自动保持有效

## 新增一个主题分区（如 05-网络）

1. 新建目录 `05-网络/`，按上面的模板写笔记
2. [[计算机相关技术知识库/首页\|首页]] 增加一个分区小节
3. [[知识库全景\|知识库全景]] 中**复制任意一个分区**（组 + 内部文本框一起复制），向右平移，改组标题和文本内容；从中心节点拖一条线连到新组
4. [[知识库目录\|知识库目录]] 增加一个 list 视图（复制现有视图，改 `file.inFolder` 的路径即可）

## 新增参考资料（PDF 等）

1. 把文件放进 `99-参考资料/资料原文/`
2. 打开 [[计算机相关技术知识库/99-参考资料/参考资料索引\|参考资料索引]]，在清单表格加一行，并在下方加 `![[文件名.pdf]]` 内嵌

## 命名与标签约定

| 约定 | 规则 | 示例 |
|------|------|------|
| 笔记名 | 「系统/主题 + 关键词」，中文为主，保留必要英文 | `Linux 文件权限`、`MySQL 增删改查` |
| 分区标签 | 一级 = 分区，二级 = 类别 | `Linux/命令`、`Windows/网络`、`数据库/MySQL` |
| 速查标签 | 所有速查表加 `速查` | `速查` |
| 文件夹编号 | `01-` 起，留出插入空间 | `02-Windows`、`05-网络` |
| 链接 | 库内一律 `[[wikilink]]`，外链才用 Markdown 链接 | `[[首页]]` |

## 更新检查清单

每次批量更新后过一遍：

- [ ] 新笔记有完整 frontmatter（title / created / tags）
- [ ] [[计算机相关技术知识库/首页\|首页]] 和 [[知识库全景\|知识库全景]] 都已挂链
- [ ] 新旧笔记之间有 wikilink 互联（非孤岛）
- [ ] [[知识库目录\|知识库目录]] 中分组正确
- [ ] 涉及命令的笔记，参数都用表格整理
