# Linux 文件系统目录结构

Linux 文件系统是**树形结构**，最顶层是根目录 `/`，所有目录、文件都挂在 `/` 下面，类似 Windows 的「此电脑」。所有操作的绝对路径都从 `/` 开始，比如 `/etc/passwd`。

> [!important] 两个关键特点
> 1. Linux 文件名**严格区分大小写**：`system` 和 `System` 是不同的文件
> 2. Linux **没有扩展名概念**：`.txt`、`.sh` 只是命名习惯，不影响文件本质

## 核心目录一览

| 目录 | 作用与说明 |
|------|-----------|
| `/`（根目录） | Linux 文件系统的最顶层，整个树形结构的起点 |
| `/bin` | **基础命令目录**。存放系统启动、维护时最必需的可执行文件，如 `ls`、`cp`、`mv`、`rm`。普通用户随时可以使用 |
| `/sbin` | **管理员命令目录**。存放系统管理、维护所需的核心可执行文件，如 `ifconfig`、`reboot`、`fdisk`。默认只允许 root 使用，普通用户需指定完整路径 |
| `/usr` | **用户资源目录**。存放系统安装的软件、命令库、文档等，包含大部分发行版的主要应用程序（如浏览器）。正常操作中不会被改变（只读） |
| `/var` | **动态数据目录**。存放系统运行过程中会变化的文件：日志、缓存、临时文件、打印队列、假脱机文件等。系统运行时会持续写入 |
| `/home` | **普通用户家目录**。每个新建普通用户都会在这里有一个同名文件夹（如 `/home/zhangsan`），存放参数配置、个性化文件、文档、数据、邮件、缓存等。系统级备份时通常必须保留 |
| `/root` | **管理员（root）家目录**。root 用户专属工作目录，普通用户无权访问 |
| `/etc` | **配置文件目录**。存放系统主要配置文件：`/etc/passwd`（用户信息）、`/etc/group`（用户组信息）、`/etc/shadow`（密码信息）、SSH/网络配置等 |
| `/dev` | **设备文件目录**。Linux 把所有硬件（硬盘、U 盘、网卡、终端）都抽象成文件，便于读写、网络共享和临时挂载 |
| `/lib` | **库文件目录**。存放系统程序运行所需的共享库、核心模块，为 `/bin` 和 `/sbin` 的命令提供运行支持 |
| `/boot` | **启动目录**。存放系统启动时的核心文件：内核文件（如 `vmlinuz`）、启动加载器（GRUB/LILO）。开机时首先读取此目录 |
| `/proc` | **进程/系统信息目录**（虚拟文件系统）。**不占用磁盘空间**，不存在于硬盘上，而是运行时在内存中生成。用于查看 CPU、内存、进程等实时状态 |
| `/opt` | **第三方软件目录**。安装可选的第三方应用程序（如商业软件、大型工具），不干扰系统原有核心文件 |
| `/tmp` | **临时文件目录**。存放各种程序产生的临时文件，所有用户可读写，**重启后自动清理** |
| `/lost+found` | **恢复文件目录**。文件系统出错（如断电）修复（fsck）时，损坏的文件片段会恢复到这里 |

## 记忆口诀

> [!tip] 分类记忆
> - **命令类**：`/bin`（大众）vs `/sbin`（root 专属）
> - **数据类**：`/usr`（静态只读）vs `/var`（动态会变）
> - **人用**：`/home`（普通用户）vs `/root`（管理员）
> - **配置**：`/etc`；**硬件**：`/dev`；**内存数据**：`/proc`
