# Linux 文件权限

Linux 是一个典型的多用户系统，不同用户处于不同地位。为保护系统安全，Linux 对不同用户访问同一文件的权限做了不同规定。

## 三类用户 × 三组权限

Linux 给每个文件/目录都分配 **3 组权限**，分别对应 3 类用户：

| 简写 | 用户 | 说明 |
|------|------|------|
| `u`（user） | 文件所有者 | 创建这个文件的人 |
| `g`（group） | 文件所属组 | 文件所有者所在组的成员 |
| `o`（others） | 其他用户 | 系统里其他所有用户 |
| `a`（all） | 所有用户 | 上面三类的总和 |

## 四种访问权限

| 权限 | 字符 | 英文 | 含义 |
|------|------|------|------|
| 可读取 | `r` | Readable | 读权限 |
| 可写入 | `w` | Writable | 写权限 |
| 可执行 | `x` | eXecute | 执行权限 |
| 无权限 | `-` | — | 没有该权限 |

## ls -la 的 10 位字符解读

```
-rw-r--r--
1 2-4 5-7 8-10
```

| 位置 | 含义 |
|------|------|
| 第 1 位 | **文件类型**：`-` 普通文件（txt、sh 等）/ `d` 目录 / `l` 软链接（快捷方式）/ `c`、`b` 设备文件（/dev 下） |
| 第 2-4 位 | **所有者（u）权限** |
| 第 5-7 位 | **所属组（g）权限** |
| 第 8-10 位 | **其他用户（o）权限** |

> [!example] 示例
> ```bash
> ls -la
> -rw-r--r-- 1 tom tom 0 Oct 13 10:00 test.txt
> ```
> `-`（普通文件）+ `rw-`（所有者可读写）+ `r--`（组内只读）+ `r--`（其他人只读）

## ls -la 输出逐列解析

`ls -l` 以**长格式**列出文件详情；`-a` 额外显示以 `.` 开头的隐藏文件（包括 `.` 当前目录和 `..` 上级目录）。两者合起来就是常用的 `ls -la`。

以一行输出为例：

```bash
-rwxr-xr-x 1 root root 0 Oct 9 17:00 per.txt
```

| 列 | 示例 | 含义 |
|----|------|------|
| 1 | `-rwxr-xr-x` | 文件类型 + 三组权限（10 位字符，见上一节） |
| 2 | `1` | 硬链接数；普通文件通常是 1，**目录的链接数 = 子目录数 + 2**（`.` 和 `..` 各占一个） |
| 3 | `root` | 所有者（属主） |
| 4 | `root` | 所属组 |
| 5 | `0` | 文件大小，单位为字节；目录本身通常显示 `4096`（占用一个块） |
| 6 | `Oct 9 17:00` | 最后修改时间 |
| 7 | `per.txt` | 文件名 |

> [!tip] 记忆顺序
> **权限 → 链接数 → 所有者 → 所属组 → 大小 → 时间 → 文件名**。

## 实战：以 root 创建文件并设置 755

```bash
sudo touch per.txt          # 以 root 身份创建空文件
sudo chmod 755 per.txt      # 把权限改为 755
ls -l per.txt               # 查看结果
```

输出类似：

```bash
-rwxr-xr-x 1 root root 0 Oct 9 17:00 per.txt
```

- `755` 展开为 `rwxr-xr-x`：所有者 `rwx`，所属组 `r-x`，其他用户 `r-x`。
- 数字来源：`7 = 4 + 2 + 1`（r + w + x），`5 = 4 + 0 + 1`（r + - + x）。

> [!warning] root 拥有的文件
> 只有文件所有者或 root 才能修改文件权限。属主是 `root` 的文件，普通用户即使能读能写，改权限也必须借助 `sudo`。

## chmod：修改权限命令

### 数字模式（最常用）

每个权限对应一个数字：`r=4`、`w=2`、`x=1`，每组权限求和：

| 常见权限 | 数字 | 含义 |
|----------|------|------|
| `rwxrwxrwx` | 777 | 所有人可读可写可执行 |
| `rw-r--r--` | 644 | 所有者读写，其他人只读 |
| `rwxr-xr-x` | 755 | 所有者全权限，其他人读+执行 |

```bash
chmod 644 test.txt       # 所有者读写，其他只读
chmod 755 test_dir/      # 所有者全权限，其他只读+执行
chmod 755 test.sh        # 让脚本文件可以执行
```

> [!tip] 数字模式心算
> `7 = rwx(4+2+1)`，`5 = r-x(4+0+1)`，`4 = r--(4+0+0)`，`6 = rw-(4+2+0)`
> 位置固定：**所有者 → 所属组 → 其他用户**，如 `750`、`600`、`644`
