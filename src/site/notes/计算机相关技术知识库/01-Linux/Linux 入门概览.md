# Linux 入门概览

## Linux 起源

Linux 内核最初只是由芬兰人**林纳斯·托瓦兹**（Linus Torvalds）在赫尔辛基大学上学时出于个人爱好而编写的。

Linux 是一套**免费使用和自由传播的类 Unix 操作系统**，是一个基于 POSIX 和 UNIX 的：

- 多用户、多任务
- 支持多线程和多 CPU
- 支持 32 位和 64 位硬件

的操作系统。Linux 能运行主要的 UNIX 工具软件、应用程序和网络协议。它继承了 Unix 以**网络为核心**的设计思想，是一个性能稳定的多用户网络操作系统。

> [!tip] 一句话记忆
> Linux = Linus 写的内核 + 各种发行版。严格说 Linux 只指内核，但日常语境下泛指整套 Linux 操作系统。

## Linux 安装（发行版）

常见的 Linux 发行版：

| 发行版 | 特点 |
|--------|------|
| CentOS 7 | 企业级稳定，服务器常用 |
| Ubuntu | 易用、社区活跃，桌面/服务器皆可 |
| Kali | 安全测试专用，预装大量渗透工具 |

## 使用工具

- **VMware 虚拟机**：在 Windows 上虚拟安装并运行 Linux

## Linux 远程连接工具（SSH 协议）

服务器上的 Linux 通常通过 SSH 远程管理，常用工具：

- windTerm
- FinalShell
- MobaXterm
- xshell

> [!info] SSH
> SSH（Secure Shell）是一种加密的网络协议，用于在不安全的网络上安全地运行网络服务。Linux 服务器的标准远程管理方式。
