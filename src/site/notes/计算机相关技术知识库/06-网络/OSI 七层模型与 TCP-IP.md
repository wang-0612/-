# OSI 七层模型与 TCP-IP

> [!abstract] 一句话区分
> **OSI 七层模型**是 ISO 提出的**理论参考模型**，用来描述网络通信应该分成哪些层；**TCP/IP** 是互联网实际使用的**协议栈**，把功能合并成四层。分析问题时可以套 OSI 的分层思路，实际通信按 TCP/IP 协议族工作。

## OSI 七层模型

OSI（Open Systems Interconnection，开放系统互连）参考模型把网络通信划分为七层。每一层为上一层提供服务，并屏蔽下层的实现细节。

| 层号 | 中文名 | 英文名 | 核心职责 | 代表协议 / 设备 |
|:---:|---|---|---|---|
| 7 | 应用层 | Application | 面向用户，为应用程序提供网络服务接口 | HTTP、HTTPS、FTP、SMTP、POP3、IMAP、DNS、SSH、Telnet、DHCP |
| 6 | 表示层 | Presentation | 数据格式转换、加密解密、压缩解压 | SSL/TLS、JPEG、GIF、MPEG、ASCII/Unicode |
| 5 | 会话层 | Session | 建立、维护、终止会话 | RPC、NetBIOS、PPTP |
| 4 | 传输层 | Transport | 端到端传输、端口寻址、可靠 / 不可靠传输 | TCP、UDP、SCTP |
| 3 | 网络层 | Network | 逻辑寻址与路由选择 | IP、ICMP、IGMP、ARP、OSPF、RIP、BGP；路由器 |
| 2 | 数据链路层 | Data Link | 成帧、差错检测、MAC 地址寻址 | Ethernet、PPP、HDLC、VLAN、STP；交换机、网桥 |
| 1 | 物理层 | Physical | 传输比特流（电信号 / 光信号 / 无线电波） | 双绞线、光纤、无线电；中继器、集线器 |

> [!tip] 记忆口诀
> **物数网传会表应** —— 从第 1 层到第 7 层依次是：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。
> 反过来从上层往下记是「应表会传网数物」。

## TCP/IP 四层模型

TCP/IP 由 ARPANET 发展而来，是互联网实际运行的基础协议族。它把 OSI 的七层合并为四层：

| TCP/IP 层 | 对应 OSI 层 | 典型协议 |
|---|---|---|
| 应用层 | 应用层 + 表示层 + 会话层 | HTTP、HTTPS、FTP、SMTP、DNS、SSH、DHCP |
| 传输层 | 传输层 | TCP、UDP、SCTP |
| 网络层（网际层） | 网络层 | IP、ICMP、IGMP、ARP、OSPF、BGP |
| 网络接口层（链路层） | 数据链路层 + 物理层 | Ethernet、PPP、Wi-Fi、VLAN |

> [!note] 教学中的五层模型
> 有些教材为了讲解方便，把 TCP/IP 拆成**五层**：物理层、数据链路层、网络层、传输层、应用层。它只是教学划分，不是另一套独立协议。

## 数据封装与解封装

发送数据时，数据从上往下逐层加头；接收时从下往上逐层拆头。以一次 HTTP 请求为例：

```
应用层：        HTTP 数据（报文）
                    ↓ 加 TCP 头（源 / 目的端口、序号等）
传输层：        段 Segment
                    ↓ 加 IP 头（源 / 目的 IP 地址等）
网络层：        包 Packet
                    ↓ 加帧头 + 帧尾（MAC 地址、FCS 校验）
数据链路层：    帧 Frame
                    ↓ 转换为电信号 / 光信号 / 无线电波
物理层：        比特 Bit（0 和 1）
```

| 层 | 数据单元（PDU） | 本层添加的信息 |
|---|---|---|
| 应用层 | 数据 Data | 应用协议报文（如 HTTP 请求行、请求头） |
| 传输层 | TCP：段 Segment；UDP：数据报 Datagram | TCP 头：端口号、序号、校验和；UDP 头：端口号、长度、校验和（无序号） |
| 网络层 | 包 Packet | IP 头：源 IP、目的 IP、TTL |
| 数据链路层 | 帧 Frame | 帧头（源 / 目的 MAC）+ 帧尾（FCS 校验） |
| 物理层 | 比特 Bit | 不添加头部，转换为信号传输 |

接收端的顺序相反：物理层 → 数据链路层 → 网络层 → 传输层 → 应用层，逐层去掉本层头部，最后把数据交给应用程序。

## 常见易错点

> [!warning] 考试易错
> - 第 2 层叫**数据链路层**（Data Link），不是「数据层」。
> - 应用层代表协议是 **HTTP / HTTPS / FTP / DNS / SMTP** 等；加密协议写作 **TLS**，不要写成「TCL」。
> - **HTTPS 默认端口是 443**，不是 8080；8080 常作为 HTTP 代理或备用 Web 端口。
> - 网络层代表协议是 **IP / ICMP / ARP / IGMP**，路由协议 OSPF、RIP、BGP 也工作在网络层。
> - 传输层代表协议是 **TCP / UDP**，SCTP 也属于传输层。
> - 物理层传输的是**比特流**，数据链路层才处理**帧**。

## 端口与分层的关系

传输层用**端口号**区分同一台主机上的不同应用进程。端口号范围 `0~65535`，共 **65536** 个；其中 0 号保留，实际可用的是 `1~65535`。

| 范围 | 类别 | 说明 |
|---|---|---|
| 0 | 保留 | 不使用 |
| 1~1023 | 知名端口（Well-known） | 固定分配给常见服务，如 22、80、443 |
| 1024~49151 | 注册端口（Registered） | 向 IANA 登记后使用，如 3306、3389 |
| 49152~65535 | 动态 / 私有端口 | 客户端临时使用 |

| 端口 | 服务 | 说明 |
|:---:|---|---|
| 22 | SSH | 加密远程登录 |
| 80 | HTTP | 明文 Web 服务 |
| 443 | HTTPS | HTTP over TLS |
| 3306 | MySQL | MySQL 数据库默认端口 |
| 3389 | RDP | Windows 远程桌面 |
