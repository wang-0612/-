# 网络基础速查

> [!abstract] 本文用途
> 一页汇总 **OSI 七层、TCP/IP 四层、常见端口、GET / POST 区别与常用网络命令**，适合考前复习与日常排查。分层细节见 [[计算机相关技术知识库/06-网络/OSI 七层模型与 TCP-IP\|OSI 七层模型与 TCP-IP]]，请求方法见 [[计算机相关技术知识库/06-网络/HTTP 请求方法\|HTTP 请求方法]]。

## OSI 七层模型

> [!tip] 记忆口诀
> **物数网传会表应** —— 从第 1 层到第 7 层依次为：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

| 层号 | 名称 | 英文 | 代表协议 / 设备 |
|:---:|---|---|---|
| 7 | 应用层 | Application | HTTP、HTTPS、FTP、SMTP、POP3、IMAP、DNS、SSH、Telnet、DHCP |
| 6 | 表示层 | Presentation | SSL/TLS、JPEG、GIF、MPEG、ASCII / Unicode |
| 5 | 会话层 | Session | RPC、NetBIOS、PPTP |
| 4 | 传输层 | Transport | TCP、UDP、SCTP |
| 3 | 网络层 | Network | IP、ICMP、IGMP、ARP、OSPF、RIP、BGP；路由器、三层交换机 |
| 2 | 数据链路层 | Data Link | Ethernet、PPP、HDLC、VLAN、STP；交换机、网桥、网卡 |
| 1 | 物理层 | Physical | 双绞线、光纤、无线电；中继器、集线器 |

> [!warning] 考试易错
> - 第 2 层是**数据链路层**，不是「数据层」。
> - 应用层加密协议写作 **TLS**，不要写成「TCL」。
> - **HTTPS 默认 443**；**8080** 是 HTTP 代理或备用 Web 端口，不是 HTTPS。

## TCP/IP 四层模型

TCP/IP 把 OSI 的七层合并为四层：

| TCP/IP 层 | 对应 OSI 层 | 代表协议 |
|---|---|---|
| 应用层 | 应用层 + 表示层 + 会话层（5~7 层） | HTTP、HTTPS、FTP、SMTP、DNS、SSH、DHCP |
| 传输层 | 传输层（第 4 层） | TCP、UDP、SCTP |
| 网络层（网际层） | 网络层（第 3 层） | IP、ICMP、IGMP、ARP、OSPF、BGP |
| 网络接口层（链路层） | 数据链路层 + 物理层（1~2 层） | Ethernet、PPP、Wi-Fi、VLAN |

> [!note] 五层教学模型
> 有些教材把 TCP/IP 拆成**五层**：应用层、传输层、网络层、数据链路层、物理层。它只是教学划分，不是另一套独立协议。

## 常见端口

端口号范围 **0~65535**，共 **65536** 个。

| 范围 | 类别 | 说明 |
|---|---|---|
| 0 | 保留 | 不使用 |
| 1~1023 | 知名端口（Well-known） | 固定分配给常见服务，如 22、80、443 |
| 1024~49151 | 注册端口（Registered） | 向 IANA 登记后使用，如 3306、3389 |
| 49152~65535 | 动态 / 私有端口 | 客户端临时使用 |

| 端口 | 服务 | 说明 |
|:---:|---|---|
| 21 | FTP | 文件传输（控制连接） |
| 22 | SSH | 加密远程登录 |
| 23 | Telnet | 明文远程登录 |
| 25 | SMTP | 发送邮件 |
| 53 | DNS | 域名解析（UDP 查询 / TCP 区域传送） |
| 80 | HTTP | 明文 Web |
| 110 | POP3 | 接收邮件（下载到本地） |
| 143 | IMAP | 接收邮件（服务器端管理） |
| 443 | HTTPS | HTTP over TLS/SSL |
| 445 | SMB | Windows 文件与打印机共享 |
| 1433 | SQL Server | 微软数据库 |
| 1521 | Oracle | Oracle 数据库监听 |
| 3306 | MySQL | MySQL / MariaDB |
| 3389 | RDP | Windows 远程桌面 |
| 6379 | Redis | 内存数据库 |
| 8080 | 备用 Web | HTTP 代理 / 备用 Web 端口 |
| 27017 | MongoDB | 文档数据库 |

> [!warning] 易错
> HTTPS 默认端口是 **443**；**8080** 是 HTTP 代理或备用 Web 端口，不是 HTTPS。

## GET 与 POST

| 对比项 | GET | POST |
|---|---|---|
| 参数位置 | URL 查询字符串（`?key=value&...`） | 请求体 body |
| 可见性 | 地址栏、浏览器历史、服务器日志中可见 | 不显示在 URL，抓包仍可见 |
| 长度限制 | HTTP 协议本身无硬性限制，受浏览器 / 服务器 URL 长度限制 | 取决于服务器配置（如请求体大小限制），通常能传更多数据 |
| 缓存 | 可被浏览器、代理、CDN 缓存 | 默认不缓存 |
| 幂等性 | 幂等、安全（只读） | 非幂等（重复提交可能重复创建数据） |
| 典型用途 | 查询、搜索、翻页、获取页面 | 登录、注册、提交表单、文件上传、修改数据 |

> [!warning] POST 不等于安全
> 明文 HTTP 下 GET 和 POST 都能被抓包；敏感数据必须用 **HTTPS**。GET 参数还会留在 URL、浏览器历史、服务器日志和 Referer 中，密码、Token 不应放在 URL。

## 常用网络命令

| 命令 | 平台 | 作用 |
|---|---|---|
| `ipconfig` | Windows | 查看 IP 地址、子网掩码、默认网关 |
| `ipconfig /all` | Windows | 查看 MAC、DHCP、DNS 等完整信息 |
| `ping 目标` | Windows / Linux | 用 ICMP 测试连通性 |
| `netstat -ano` | Windows | 显示所有连接和监听端口，数字形式，附 PID |
| `ifconfig` | Linux | 查看 / 配置网卡（net-tools，较旧） |
| `ip addr` | Linux | 查看网卡与 IP（iproute2，推荐） |
| `ss -tuln` | Linux | 查看 TCP / UDP 监听端口 |
| `curl -I URL` | Windows / Linux | 只请求并显示 HTTP 响应头 |
| `nslookup 域名` | Windows / Linux | 查询 DNS 解析结果 |

### Windows

```bash
ipconfig                        # 查看 IP 地址、子网掩码、默认网关
ipconfig /all                   # 查看 MAC、DHCP、DNS 等完整信息
ping www.baidu.com              # 测试连通性（ICMP）
netstat -ano                    # 所有连接和监听端口，数字显示，附 PID
netstat -ano | findstr :3389    # 查看 3389 端口占用
nslookup www.baidu.com          # 查询 DNS 解析结果
curl -I https://www.baidu.com   # 只取 HTTP 响应头
```

### Linux

```bash
ip addr                         # 查看网卡与 IP（推荐）
ifconfig                        # 查看网卡与 IP（旧命令，需 net-tools）
ss -tuln                        # 查看 TCP / UDP 监听端口
ping -c 4 8.8.8.8               # 发送 4 个 ICMP 包
nslookup www.baidu.com          # 查询 DNS 解析结果
curl -I https://www.baidu.com   # 只取 HTTP 响应头
```

### 常用参数

| 参数 | 所属命令 | 含义 |
|---|---|---|
| `-a` | netstat | 显示所有连接和监听端口 |
| `-n` | netstat / ss | 以数字显示 IP 和端口，不解析域名 |
| `-o` | netstat | 显示连接对应的进程 PID |
| `-t` | ss | 只看 TCP |
| `-u` | ss | 只看 UDP |
| `-l` | ss | 只看监听状态 |
| `-p` | ss | 显示对应进程（通常需要 root） |
| `/all` | ipconfig | 显示完整网络配置 |
| `-I` | curl | 只请求响应头（HEAD） |

> [!tip] 端口占用排查
> - Windows：`netstat -ano | findstr :8080` 找到 PID，再用 `tasklist | findstr PID` 查看程序。
> - Linux：`ss -tulnp | grep 3306` 直接查看监听进程（`-p` 通常需要 root）。
