# 信息收集速查

一页汇总域名、端口、目录、指纹与 CDN 的常用工具和命令。

> [!warning] 合规声明
> 仅在授权范围内对目标进行信息收集。

## 域名与 IP

```bash
ping 域名                 # DNS 解析
nslookup 域名             # 查询域名对应 IP
nslookup 域名 8.8.8.8     # 指定 DNS 服务器
```

| 用途 | 平台 |
|------|------|
| IP 反查域名 | https://site.ip138.com/ 、https://www.webscan.cc/ |
| IP 反查域名 | https://www.virustotal.com 、https://x.threatbook.cn/ |
| Whois | https://whois.aizhan.com 、http://whois.chinaz.com |
| ICP 备案 | https://beian.miit.gov.cn/ 、http://www.beian.gov.cn/portal/recordQuery |
| 子域名 | https://www.virustotal.com/gui/home/search 、https://fofa.info/ |
| 子域名工具 | Layer 子域名挖掘机 |

### nmap

```bash
nmap 192.168.1.1/24                                    # 默认扫描 1-10000
nmap -sP 192.168.1.0/24                                # Ping 扫描
nmap -O 192.168.1.1                                    # 系统探测
nmap -A 192.168.1.1                                    # 全面探测
nmap -sS 192.168.1.1 -p 1-3000 --open -vv              # 快速扫描
nmap -sT 192.168.1.1 -p 21,22,80,443,3306              # TCP 全连接
nmap -PN 192.168.1.1 -p 1-3000                         # 禁 Ping 主机
nmap -PR 192.168.1.1 -p 1-3000                         # ARP 扫描（内网快）
nmap -P0 192.168.1.1 -p 1-3000                         # 空闲扫描
nmap -sV -A 192.168.1.1 -p 80,443,3306 -oX out.xml     # 版本 + 输出 XML
```

| 参数 | 作用 |
|------|------|
| `-sS` | SYN 半开放扫描（常用） |
| `-sT` | TCP 全连接扫描（默认） |
| `-sU` | UDP 扫描（不准确） |
| `-sV` | 服务与版本 |
| `-O` | 操作系统 |
| `-A` | 全面探测（有误报） |
| `-p` | 指定端口 |
| `-PN` | 不使用 Ping |
| `-PR` | ARP Ping |
| `--open` | 只显示开放端口 |
| `-oN/-oX/-oG` | 文本 / XML / grepable 输出 |

### masscan

```bash
masscan 192.168.1.1 -p 1-3000
masscan 192.168.1.1/24 --ping                          # ICMP 探测在线主机
masscan -sL 10.0.0.0/24 > c段.txt                      # 枚举网段
masscan 192.168.1.1/24 -p 21,22,80,443,3306 --open-only
```

常用参数：`--rate 1000~3000`、`--open-only`、`--banners`、`--exclude`、`-iL`、`-oX/-oJ`。

## 目录

```bash
python dirsearch.py -u http://target.com
python dirsearch.py -u http://target.com -e php,asp,aspx,jsp,bak -t 30
python dirsearch.py -u http://target.com -r -x 404,403
python dirsearch.py -u http://target.com --proxy 127.0.0.1:8080 --random-agents
```

| 参数 | 作用 |
|------|------|
| `-u` | 目标 URL |
| `-e` | 扩展名，`*` 为全部 |
| `-w` | 字典 |
| `-t` | 线程（默认 25） |
| `-r` | 递归 |
| `-x` | 排除状态码 |
| `--exclude-texts` | 按文本排除 |
| `--format` | 报告格式 |
| `-o` | 输出文件 |

先看 `robots.txt`：

```text
https://target.com/robots.txt
```

## 指纹

```bash
whatweb 域名
certutil -hashfile favicon.ico MD5
```

| 平台 | 地址 |
|------|------|
| 在线指纹 | http://whatweb.bugscaner.com/ |
| Wappalyzer | 浏览器插件 |

识别对象：CMS、前端框架、Web 服务器、应用服务器、开发语言、操作系统、CDN、WAF、IP/域名、端口。

## CDN

```bash
nslookup 域名
```

| 方法 | 地址 |
|------|------|
| 多地 Ping | https://ping.chinaz.com/ |
| 多地 Ping | https://tools.ipip.net/ping.php |
| 在线识别 | https://www.cdnplanet.com/tools/cdnfinder |

判断：多地 ping 返回多个不同 IP、CNAME 指向 CDN 厂商域名。
