# 搜索语法速查

一页汇总 Google / Bing / FOFA / Quake / Hunter 的常用检索语法。

> [!warning] 合规声明
> 仅检索公开信息，不得用于定位并攻击未授权资产。

## Google 基础

| 语法 | 含义 | 示例 |
|------|------|------|
| 空格 / `AND` | 同时包含（默认） | `program google` |
| `OR` 或 `|` | 任一包含（必须大写） | `program OR google` |
| `""` | 精确词组 | `"programgoogle"` |
| `-` | 排除（前有空格） | `program -google` |
| `+` | 强制包含 | `+www` |
| `*` / `?` | 通配占位 | `"l*Messi"` |

## Google 高级

| 语法 | 作用 |
|------|------|
| `site:` | 限定域名 |
| `inurl:` | URL 中包含 |
| `intext:` | 正文包含 |
| `intitle:` | 标题包含 |
| `filetype:` | 文件类型 |
| `inanchor:` | 锚文本 |
| `cache:` | 缓存页面 |

## 常用 Google Hacking 组合

```text
# 后台地址
site:域名 inurl:login|admin|manage|member|admin_login|login_admin|system|user|main|cms

# 文本内容
site:域名 intext:管理|后台|登陆|用户名|密码|验证码|系统|admin|login|sys|password|username

# 可注入点
site:域名 inurl:aspx|jsp|php|asp

# 上传点
site:域名 inurl:file|load|editor|Files

# Web 编辑器
site:域名 inurl:ewebeditor|editor|uploadfile|eweb|edit

# 数据库文件
site:域名 filetype:mdb|asp|#

# 脚本类型
site:域名 filetype:asp|aspx|php|jsp

# 目录穿越式入口
inurl:cms/data/templates/images/index/

# 正文 / 标题 / 锚文本
inbody:密码|登陆
intitle:后台管理
inanchor:登录
```

## Bing

| 语法 | 作用 |
|------|------|
| `site:` | 限定网站，多域用 `OR` 分组 |
| `inurl:` | URL 包含 |
| `intitle:` | 标题包含 |
| `inbody:` | 正文包含 |
| `inanchor:` | 锚节点包含 |
| `filetype:` | 文件类型 |
| `ip:` | 指定 IP 的网站 |

## FOFA

地址：https://fofa.info/

逻辑：`&&`（与）、`||`（或）、`!=`（非）、括号分组。

| 语法 | 作用 |
|------|------|
| `domain="qq.com"` | 查询子域名 |
| `host=".gov.cn"` | URL 中包含 |
| `header="thinkphp"` | HTTP 头包含 |
| `port="6379"` | 指定端口资产 |
| `ip="1.1.1.1"` | 指定 IP |
| `ip="220.181.111.1/24"` | C 段 |
| `status_code="402"` | 状态码 |
| `app="通达OA网络智能办公系统"` | 指定应用 |
| `country="CN"` | 国家 |
| `region="Henan"` | 行政区 |
| `city="beijing"` | 城市 |

组合示例：

```text
title="powered by" && title!="discuz"

body="content=WordPress" || (header="X-Pingback" && header="/xmlrpc.php" && body="/wp-includes/") && host="gov.cn"
```
